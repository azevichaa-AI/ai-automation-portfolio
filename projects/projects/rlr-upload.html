Retail Label Recognition / RLR

Working web demo: upload a price tag image, send it to a live FastAPI backend, run OCR, and extract price/code candidates.

Project idea

Retail Label Recognition is a computer vision and OCR pipeline for extracting structured information from retail price labels: prices, product codes, barcode candidates and OCR text.

This public demo uses a lightweight OCR backend on a small VPS. The full research version can include YOLO detection, crop selection, barcode/QR decoding, PaddleOCR/Tesseract variants and CSV export.

Upload price tag image
